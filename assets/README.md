# Plugin Assets (WordPress.org)

This folder holds the assets shown on the WordPress.org plugin page. These mirror
what you upload to the plugin's `assets` directory in the SVN repository.

Required files once you have them (add to this folder and to SVN `assets/`):

- `icon-128x128.png` / `icon-128x128.gif` (or SVG) - plugin icon
- `icon-256x256.png` / `icon-256x256.gif` (or SVG) - plugin icon (retina)
- `banner-772x250.png` (or JPG) - plugin banner
- `banner-1544x500.png` (or JPG) - plugin banner (retina)
- `screenshot-1.png` ... `screenshot-N.png` - login page screenshots

Screenshots referenced in `trunk/readme.txt` must match files present here.
